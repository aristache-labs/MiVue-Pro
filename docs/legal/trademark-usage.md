# Reguli de utilizare a mărcilor „Mio” și „MiVue”

**Versiune:** 0.1  
**Data:** 19 iulie 2026  
**Nume produs:** `[NUMELE_APLICAȚIEI]`

## 1. Principiu

„Mio”, „MiVue” și eventualele mărci/logouri asociate sunt tratate ca semne ale titularilor lor, nu ca active ale proiectului. Folosirea propusă este numai factuală și descriptivă, strict cât este necesar pentru a explica destinația sau compatibilitatea testată a unui produs independent.

[Articolul 14 din Regulamentul (UE) 2017/1001](https://eur-lex.europa.eu/eli/reg/2017/1001/oj/eng) limitează în anumite condiții efectele mărcii UE, inclusiv pentru referirea la bunurile/serviciile titularului și indicarea destinației, dar numai dacă folosirea respectă practicile loiale în materie industrială sau comercială. Aplicarea la numele, metadata și marketingul concret trebuie confirmată de avocat.

## 2. Utilizări propuse, supuse aprobării

- în lista de compatibilitate: „Testat cu camera Mio MiVue 866, firmware `[VERSIUNE]`”;
- într-o instrucțiune tehnică: „Conectați telefonul la rețeaua Wi‑Fi creată de cameră”;
- într-un disclaimer clar, apropiat de prima afirmație de compatibilitate;
- în cuvinte simple, fără logo, font, culoare, casing sau tratament grafic care sugerează o origine comună;
- numai pentru modelele și firmware-urile testate, cu data și limitările vizibile.

## 3. Utilizări interzise fără permisiune scrisă

- „Mio”, „MiVue”, „MiVue Pro” sau variații confuz similare în numele principal al aplicației, numele companiei, domeniu, bundle/package ID sau cont social;
- logouri, wordmarks stilizate, iconografie, splash screen, screenshot-uri, fotografii de produs ori elemente UI preluate de la MiTAC;
- formulări precum „oficial”, „certificat”, „aprobat”, „partener”, „powered by” sau „garantat compatibil”;
- imitarea aspectului aplicației MiVue Pro ori a ambalajului camerei;
- cumpărarea de keywords/ads sau metadata care creează impresia că aplicația este produsul titularului mărcii;
- folosirea mărcii ca verb, nume generic sau element dominant;
- combinarea disclaimer-ului cu o prezentare care, per ansamblu, continuă să sugereze afilierea.

## 4. Disclaimer obligatoriu — draft

> `[NUMELE_APLICAȚIEI]` este o aplicație independentă și nu este afiliată, sponsorizată, aprobată sau susținută de MiTAC ori de titularii mărcilor Mio/MiVue. „Mio” și „MiVue” sunt folosite numai descriptiv pentru a identifica dispozitivele cu care compatibilitatea a fost testată. Toate mărcile aparțin titularilor lor.

Avocatul trebuie să confirme entitatea juridică exactă, titularii mărcilor și traducerile înainte de publicare.

## 5. Model de afirmație de compatibilitate

> Compatibilitate testată: Mio MiVue 866, firmware `[VERSIUNE]`, pentru listare și descărcare locală read-only. Alte modele sau versiuni pot funcționa diferit. Aplicația nu modifică setările și nu șterge fișiere de pe cameră.

Nu se folosește o listă de modele dedusă din APK sau din marketingul producătorului. Fiecare intrare trebuie susținută prin teste autorizate și o fișă de compatibilitate datată.

## 6. Reguli pentru store listing și UI

| Suprafață | Regulă |
|---|---|
| nume și icon | brand propriu, după trademark clearance; fără semne/forme MiTAC |
| subtitle/short description | funcția proprie înaintea compatibilității; marca terță nu este element dominant |
| descriere lungă | afirmații precise, datate, limitate la funcții testate; disclaimer vizibil |
| screenshots/video | UI și active proprii/sintetice; fără UI, logo sau conținut protejat MiTAC fără permisiune |
| onboarding | referire descriptivă numai când utilizatorul selectează/conectează modelul |
| User-Agent, GPX, loguri | identificator și namespace proprii; fără `MiVuePro-Research`, `MiVue 866 CLI` sau domenii ce includ marca |
| suport/website | pagină de compatibilitate și neafiliere; fără trade dress similar |

## 7. Verificări înainte de alegerea numelui

- căutare EUIPO, OSIM și în jurisdicțiile de distribuție;
- căutare în App Store, Google Play, domenii și nume comerciale;
- analiză similaritate vizuală, fonetică și conceptuală în clasele relevante;
- verificarea iconului, subtitle-ului și keyword-urilor ca ansamblu;
- opinie scrisă de clearance și înregistrare proprie, dacă se recomandă;
- verificarea titularilor actuali ai mărcilor „Mio”/„MiVue”.

## 8. Contact MiTAC

O solicitare de clarificare/autorizare trebuie să descrie exact funcțiile read-only, modelele, folosirea de marcă și activele propuse. Se păstrează dovada transmiterii și răspunsul. Lipsa răspunsului nu este acord și nu elimină obligația de practici comerciale oneste.
